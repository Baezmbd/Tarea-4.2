Tarea 4.2 - Aplicación de CSS

Estudiante: Mario Baez
Curso: WADE1000L Front End Programming

Descripción del proyecto:

En esta tarea se desarrolló una página web utilizando HTML5 y CSS con el propósito de aplicar los conceptos estudiados en el módulo sobre estilos visuales y diseño web.

La página utiliza una estructura semántica compuesta por las etiquetas header, nav, main, section, article y footer para organizar adecuadamente el contenido. Además, se implementó un archivo CSS externo para separar la presentación del contenido y mejorar la apariencia visual del sitio.

Durante el desarrollo se aplicaron diferentes tipos de selectores CSS, incluyendo selectores de elementos, clases e identificadores. También se utilizaron diversas propiedades CSS para modificar colores, tamaños de texto, márgenes, rellenos, fondos y alineación de elementos.

Se implementó el modelo de caja (Box Model) mediante el uso de padding, margin, border y border-radius para crear secciones visualmente organizadas. Asimismo, se añadieron sombras y efectos visuales para mejorar la presentación de la página.

El proyecto incluye diseño responsivo mediante Media Queries, permitiendo que el contenido se adapte correctamente a diferentes tamaños de pantalla y dispositivos.

La página fue publicada utilizando GitHub y GitHub Pages para permitir su acceso en línea.
